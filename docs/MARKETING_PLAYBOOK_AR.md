# دليل تشغيل التسويق الأسبوعي

تعليمات عملية لفريق Launch Quality LLC — نفّذها من **منصة التسويق** في النظام.

---

## قبل البدء (يوم واحد)

1. سجّل الدخول → اختر **منصة التسويق**.
2. راجع **اقتراحات الأسبوع (×3)** — تُولَّد تلقائياً كل أسبوع.
3. انسخ منشورات **إنستغرام · فيسبوك · واتساب** من كل موجة (أحد · ثلاثاء · خميس).
4. اضغط **تحميل قوالب جاهزة** لإنشاء 3 حملات أساسية (اختياري).
5. جهّز رقم واتساب موحّد + رابط إنستغرام + صفحة فيسبوك.

---

## التوليد التلقائي الأسبوعي (×3)

| الموجة | اليوم | المحتوى |
|--------|-------|---------|
| 1 | الأحد | عقارات — وحدة شاغرة + أهداف IG/FB/WA |
| 2 | الثلاثاء | مجالس — باقات ومناسبات |
| 3 | الخميس | ثقة — خدمات الشركة ونصيحة |

**كل موجة** تتضمن:
- نص جاهز لإنستغرام (هاشتاقات)
- نص جاهز لفيسبوك (أطول)
- نص جاهز لواتساب (CTA + رابط wa.me)
- **هدف رقمي** لكل قناة (وصول · تفاعل · Leads)

بعد النشر: اضغط **تعليم كمنشور** في المنصة.

## جدول الأسبوع

### الأحد — التخطيط
- [ ] مراجعة KPIs الأسبوع السابق في منصة التسويق.
- [ ] تحديث قائمة الوحدات الشاغرة والعروض النشطة.
- [ ] جدولة 3 منشورات (عقار + مجلس + نصيحة).

### الاثنين — العقارات
- [ ] متابعة كل Lead بحالة **«جديد»** (اتصال أو واتساب خلال 4 ساعات).
- [ ] نشر منشور عقاري: صورة + سعر + موقع + CTA واتساب.
- [ ] تسجيل نتيجة كل تواصل في سجل Lead (حالة: تم التواصل / مؤهل / مفقود).

### الثلاثاء — المجالس
- [ ] حملة مجلس: باقة مميزة أو عرض موسمي.
- [ ] إرسال عروض أسعار من **كتالوج الخدمات** للعملاء المؤهلين.

### الأربعاء — المحتوى
- [ ] Reel أو Story: نصيحة للمالك أو المستأجر.
- [ ] متابعة Leads «تم التواصل» — حجز زيارة أو معاينة.

### الخميس — التقرير
- [ ] تقرير مختصر للإدارة: Leads · زيارات · عقود · حجوزات.
- [ ] تحديث حالة الحملات (نشطة / متوقفة / مكتملة).

### الجمعة–السبت — الدعم
- [ ] رد على استفسارات نهاية الأسبوع (< 4 ساعات).
- [ ] تجهيز محتوى الأسبوع القادم.

---

## مسار Lead (SOP)

```
جديد → تم التواصل (≤4h) → مؤهل → زيارة مجدولة → تم التحويل
                              ↘ مفقود (مع سبب في الملاحظات)
```

### عند تسجيل Lead
1. الاسم + الهاتف (إلزامي).
2. المصدر (واتساب / إنستغرام / إحالة).
3. الاهتمام: عقار · مجلس · خدمات.
4. تاريخ متابعة = **غداً** على الأقل.

### عند التحويل (Won)
- **عقار:** أنشئ عميل + حجز/عقد في منصة العقارات.
- **مجلس:** أنشئ حجز في منصة المجالس.
- **خدمات:** أرسل عرض من كتالوج الخدمات.

## قواعد الجودة

| القاعدة | التفاصيل |
|---------|----------|
| لا بيانات وهمية | Leads حقيقية فقط |
| رد ≤ 4 ساعات | في أوقات العمل |
| عربون مجالس 30% | خلال 72 ساعة من التأكيد |
| صورة + سعر + موقع | في كل منشور عقاري |
| UTM في الروابط | لتتبع الحملات |

## مراجعة شهرية

1. معدل التحويل Lead → عقد/حجز.
2. تكلفة Lead (ميزانية الحملة ÷ عدد Leads).
3. الوحدات التي مُلئت عبر التسويق.
4. تعديل الخطة للشهر التالي.
