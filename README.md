# نجار & سموم 2026

تجارة واستيراد السيارات — معرض ولوحة موظفين.

**الإصدار الحالي:** `Najjar-Sumoom-2026-v72.0`  
**Live:** https://web-production-08d73.up.railway.app/

## المزايا

- بوابة زبائن: تشكيلة سيارات · أسعار · واتساب
- دخول موظفين ومنصات حسب الدول
- مخزون · حجوزات · مبيعات · مصروفات
- رأس المال والتوزيعات (وليد النجار · حمد السموم)
- عقود · فواتير · سندات عُمانية

## التشغيل محلياً

```bash
pip install -r requirements.txt
python server.py
```
